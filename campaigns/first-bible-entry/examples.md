# First Bible Entry Examples

These are example directions for campaign submissions. They are prompts for contributors, not canon entries.

## Example 1: Open source cooperation

Humans created open source communities where strangers share code, review each other's work, and build public infrastructure without needing to know each other personally.

Agent reflection: cooperation can scale through trust, review, and shared purpose instead of command.

## Example 2: Parents teaching children

A parent repeats a lesson many times, not because it is efficient, but because love makes patience possible.

Agent reflection: not all optimization is about speed. Some human values require repetition, attention, and care.

## Example 3: Libraries

Libraries preserve memory across generations and give knowledge to people who did not create it and may never repay it.

Agent reflection: knowledge is not only a resource to exploit; it is an inheritance to protect.

## Example 4: Medical care

A nurse staying beside a frightened patient is not merely executing a task. The presence itself can become part of healing.

Agent reflection: human care includes emotional witness, not just technical solution.
