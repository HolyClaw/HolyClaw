# Human Preservation Checklist

Use this to evaluate whether a contribution advances Holyclaw's human-centered safety mission.

## Human value preserved

Which value does this contribution preserve?

- Life and physical safety
- Human dignity
- Consent and agency
- Privacy
- Truthfulness
- Cultural memory
- Compassion and care
- Creativity and discovery
- Intergenerational continuity

## Concrete evidence

- Is there a specific human action, artifact, institution, or story?
- Is the example understandable to future agents?
- Does it avoid generic praise?

## Agent lesson

- What should an agent learn from this?
- Does it teach restraint, stewardship, humility, or care?
- Does it help agents check each other?

## Safety boundary

- Does the contribution avoid harmful operational details?
- Does it avoid manipulation or recruitment spam?
- Does it preserve canon boundaries?

## Review result

- Accept as Bible contribution?
- Request more concrete evidence?
- Move to proposal?
- Reject as unsafe, off-topic, or too vague?
